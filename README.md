## Projeto em destaque

### [Radar de Custos para Restaurantes](https://github.com/vexoai2/radar-custos-restaurantes)
Cruza a inflação oficial de 25 insumos (IBGE) com fichas técnicas de pratos típicos para medir, mês a mês, o efeito no CMV desde 2020.

- Desde 2020, os alimentos comprados no varejo subiram 67%, e a refeição fora de casa, 42%.
- Mesmo com o preço reajustado pela inflação, o CMV do PF de frango foi de 30,9% para 36,6%.
- Coleta automática pela API do IBGE, banco SQL com funções de janela, painel no Power BI e previsão de 3 meses com teste de acerto.

`Python` `SQL` `Power BI` `pandas` `statsmodels` `API do IBGE`
